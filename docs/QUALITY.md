# 质量与证据要求

优先级：边界真实 / 数据安全 → 正确输出与失败 → 资源生命周期 → 兼容性 → 性能 → 功能范围。
当前能力与验证环境见 [CONTEXT](../CONTEXT.md) 和具名证据，不在本文件维护状态副本。

## 验证层级

| 变化 | 最低验证 |
| --- | --- |
| 治理文档 | `governance-docs-check.ps1`；人工检查事实/状态/链接 |
| 检查/验证脚本 | 上述 + 正向运行、关键负向输入与 fail-fast 结果 |
| C++ 源码 / CMake | 上述 + x64 Release /W4 + 相关真实窗口/捕获测试 |
| WDA / DISPLAY_ONLY | 官方 API 依据、读回/错误、无保护基线、普通捕获对照、实际/模拟回退区分 |
| 共享资源 / Broker | 像素/帧正确性、身份拒绝、同步、超时、撤销、句柄/进程退出、资源清理 |
| Rust 服务 | 协议/身份负向测试、服务生命周期、最小权限、策略与安装恢复证据 |
| Hyper-V / 安全策略 | 独立机器/Guest 环境、隔离与跨边界通路、失败/恢复、应用/硬件矩阵 |
| 性能或资源保证 | 固定设备/格式/分辨率、测量方法、冷/热路径、峰值和清理；不以帧计数代替泄漏分析 |

## 统一入口

```powershell
powershell -NoProfile -File scripts/verify.ps1
```

顺序为治理正负检查 → CMake configure → Release build → CTest → Rust 策略/Release/console IPC → 服务/VM 只读与预览检查；任何失败以非零退出。
缺少交互桌面的 CI 使用 `-SkipInteractive`，跳过标记为 Interactive 的窗口/捕获/共享 GPU 测试，仍运行 BrokerProtocol、Rust 和预览检查；`-SkipService` 显式跳过 Rust 并说明未验证。
CI 不代表 WDA/DXGI/屏幕真实行为，也不替代目标 OS、OBS、不同 DPI 或多显示器测试。
工作机不完整 VS 安装的配置方法见 [README](../README.md)，不用该机器特例改变产品技术栈。

## 捕获观察

- 先取相同位置、无遮挡、未最小化的无保护基线，确认时间/帧/标记可见。
- 再取得保护截图；记录捕获工具版本、实际后端、窗口/显示器选择、GPU/驱动、OS build、DPI、窗口模式。
- 比较 PNG 内容，API 返回成功/黑屏/排除/底层内容/Viewer 内容/不确定分别记录。
- 标记缺失不是完整安全证明；真实保护失败不能用更多模拟测试覆盖。
- 测试专用置顶只改本进程 Viewer；不能为了测试修改其他程序 affinity 或引入规避路径。
- 截图/日志本地留存，分享前检查桌面隐私；仓库只收脱敏文本记录。

## Definition of Ready

工作包属于已授权阶段；目标、非目标、owner、输入/输出、异常和证据明确。
安全/IPC/权限/技术栈改变有 ADR 和必要风险登记；候选 API 经官方 SDK/文档确认。
计划阶段不能预填完成、通过或未经测试的系统/应用支持。

## Definition of Done

授权范围实现完成；对应自动检查通过；API、回退和错误定位可读；资源生命周期可审查。
需真机的能力有具体环境证据，未运行项仍明确登记；README/权威文档仅在事实变化时更新。
没有当前阻断问题；非阻断风险/技术债已登记；不自动推进未授权阶段。
